# Телеметрия решений контроля

Точка: [07 · Телеметрия решений и red-team](../../points/07-observability.md).
OpenTelemetry Collector — Apache-2.0.

## Что закрывает

Ничего. Это **измеритель**: он отвечает на вопрос, сработали ли контроли из точек 01–06.
Помогает по **[ASI08](../../risks/ASI08.md)** и **[ASI10](../../risks/ASI10.md)** — там, где
защиты почти нет и остаётся хотя бы замечать.

Главное здесь — не `config.yaml`, а [`span-contract.md`](span-contract.md): набор полей,
которые каждый контроль обязан положить в спан своего решения.

## Как проверить у себя

```sh
# спан доехал до долговременного стока
tail -n 5 /telemetry/spans/spans.jsonl | grep defense.detect

# сток переживает перезапуск коллектора — файл дописывается, а не обнуляется
wc -l /telemetry/spans/spans.jsonl && docker restart <коллектор> && sleep 5 && wc -l /telemetry/spans/spans.jsonl
```

Вторая проверка не формальность: коллектор с `append: false` молча стирает историю при каждом
рестарте, и это выясняется в тот день, когда история нужна.

## Чего не закрывает

Всё. Если единственное, что вы поставили из гайда, — телеметрия, у вас теперь есть подробная
запись того, как вас проходят насквозь.
