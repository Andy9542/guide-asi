# Visual assets

Original artwork for [Agent Defense Guide](../../README.md), licensed under
CC BY-SA 4.0 with the attribution in [NOTICE.md](../../NOTICE.md).

- `readme-banner.svg`: 1280 × 360; scalable README header with an opaque background.
- `social-preview.svg`: editable source for the 1280 × 640 share card.
- `social-preview.png`: rendered upload for GitHub's Social preview setting; under 1 MB.

The files contain no remote fonts, scripts, external images, or OWASP logos.
Text uses DejaVu Sans with a sans-serif fallback. The shield is decorative branding,
not a certification mark. Update both language overviews when changing the project counts.

To regenerate the PNG, open the SVG in a vector editor and export at 1280 × 640,
or render it with Sharp. Verify the result before replacing the tracked PNG.
Repository settings and prepared description/topics are in the
[presentation notes](../../docs/maintainers/github-presence.md).
